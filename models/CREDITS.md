# Modèles 3D d'Axolo Run

Tous sous licence **CC0 1.0** (domaine public), de [Quaternius](https://quaternius.com) :

- `decor.glb` : sélection du *Stylized Nature MegaKit* (version Standard gratuite), textures réduites et converties en WebP.
- `fish1.glb`, `fish2.glb`, `fish3.glb`, `dolphin.glb`, `mantaray.glb`, `whale.glb` : *LowPoly Animated Fish*, convertis de FBX en glTF binaire.

L'axolotl n'est pas un fichier : il est modélisé dans `js/run-3d.js`.
